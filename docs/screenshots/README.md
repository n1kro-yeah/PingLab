# Скриншоты

Сюда кладутся картинки для главного `README.md`. Таблица в корневом README ссылается на фиксированные имена:

| Файл | Экран |
| --- | --- |
| `01-dashboard.jpg` | Обзор: карточка сети, доступность, список хостов |
| `02-live.jpg` | Пинг: график и лог в реальном времени |
| `03-tools.jpg` | Утилиты: traceroute, DNS, порты, TLS, WOL |
| `04-theme.jpg` | Тема: палитры Material 3 |

Рекомендации:

- скриншоты с телефона в портретной ориентации, ширина от 900 px;
- JPG для фотореалистичных кадров, PNG — если важна чёткость текста;
- один кадр желательно снять в светлой теме, один — в тёмной;
- не забывайте замазать внутренние IP и имена хостов, если они чувствительны.
