# Скриншоты

Картинки для README. Сняты на Xiaomi 14T (Android 15), светлая тема, янтарная палитра, сборка 1.1.

| Файл | Что на нём |
| --- | --- |
| `01-dashboard.jpg` | Обзор: карточка сети (LTE+, оператор, шкала сигнала), доступность за 24 часа, переключатель фонового мониторинга |
| `02-dashboard-hosts.jpg` | Обзор: плитки хостов со спарклайнами и статусами UP / DEGRADED |
| `03-live.jpg` | Пинг: живой график RTT, выбор протокола, интервал проб |
| `04-hosts.jpg` | Хосты: список с протоколом, интервалом, таймаутом и порядком |
| `05-host-detail.jpg` | Карточка хоста: окна 1ч / 6ч / 24ч / 7д, график задержки, качество связи |
| `06-tools.jpg` | Утилиты: сканер портов, который ловит прозрачный прокси и не врёт про «все открыты» |
| `07-theme.jpg` | Тема: тональные палитры Material 3 и режимы оформления |

Если меняешь скриншоты, держи тот же формат:

- ширина 540 px, JPEG, качество ~84 — файл выходит 40–60 КБ;
- метаданные вырезаны: `magick in.jpg -resize 540x -strip -interlace Plane -quality 84 out.jpg`;
- имя = номер по порядку + экран, иначе таблица в README разъедется.
